### 攻击后确认成立的要点（负面清单——SA1 不必再动）

- **E305 语义相位裁决（§5.1）**：规格 `v1-spec.md:270-272`「仅当模块全量解析成功，才进入引用/语义相位（E106 与 E301 / E302 / **E304~E309**）」——E305 字面落在 E304~E309 区间记法内；`v1-spec.md:329` 的排除清单是「别名解析与声明顺序无关」的解析时机条款，E302/E308 同被排除且同为语义相位（`semantic.ts` 现状 + #5 三层评审先例）。两份清单各归其位，论证成立。T3/T4 的相位判别输入设计正确（锚点除 #4 外复算无误）。
- **`/**/` / `/***/` 分类算法（§3.1）**：逐字符复算——`/**/` close=open+2、`/***/` close=open+3、`/** d */` body=`' d '`、`/*** d */`（body 首字符为 `*`）落入 doc、`/******/`（body=`**`）落入 doc——分类规则与规格 §5 边界条款逐例吻合，无第三种误分类路径（close=open+3 除 `/***/` 外不可构造）。
- **docTotal 不变量会计（§4.5）**：error 记号携 pending、parser 读到即抛、正常返回路径无 error 记号——「不变量在正常返回路径上永远可达且平衡」的自洽性论证经推演成立（含 `/** d */ $` 词法错误场景）。
- **五标记统一接受 vs YMap 特例 vs Record（§1.2）**：Record 不属六标记（规格 §3/§6），挂载位不含 Record——排除 Record 无规格矛盾；YMap-only 特例的否决论证成立；行为变化表与既有 37 用例的零冲突经 grep 实证（既有测试输入无任何标记拼写、无 Record、无精确 IR 形状断言，`toEqual` 仅用于 JSON 往返自等与互比）。
- **marker 语法细节（§4.3）**：`>>` 无拆分问题（tokenizer punct 单字符）、`YMap<Foo<bar>>` 经 generic-diag 循环不叠栈、`YMap<>`/`YMap<string, number>`/裸 `YMap` 的 E100 归宿、`YMap<\| string>` 前导 `|` 可推导性——逐一推演无误。
- **M1/M2/M3 锚位与挂靠机制（§2/§4.2）**：与 `parser.ts` 现状消费点逐一比对，三锚位的 token 均在挂靠点被消费，机制可行；`type /** d */ interface A {}` 等「doc + 语法相位抛错」场景的相位归宿（语法错先报、E305 不浮出）符合分相位规则。
- **IR 形状（§7）**：`docs: string[]` 必填、插入序固定、marker 单节点 + name 源拼写、`ref.name` 与标记拼写无碰撞——理由链完整；AC2 互比（docs:[] 两侧一致）与 SA6 用例 2/3/5/6/7 的断言机制经实测可满足（对照 #1：仅用例 1 的控制字符/引号形态不可满足）。

## 错误处理链路审查

（本任务为纯函数 parser 库，无 UI/异步/外部服务，按四项立法对号入座）

- **静默失败**：✅ 构造性排除——本 issue 的病灶（doc 静默丢弃）由 docTotal 不变量（任何一条 doc 既未挂载也未记悬空 → 响亮 throw → E100 内部错误）+ E305（悬空显式报错）双保险覆盖。但见 #3：`|` 消费点漏记账时，防静默机制本身会产生**错误报码**（E100 内部错误而非 E305）——静默被消灭，报码正确性仍有缺口，已列修订要求。
- **状态闭环**：✅ 全部失败路径（词法 error 记号、语法 VfslSyntaxError、语义候选、docTotal/内部异常）均收敛到 `{ ok:false, issues:[…] }` 恰 1 条，`parseVfsl` 不抛错承诺维持（#2 的爆栈场景被顶层兜底收敛为结构化错误——「不崩」成立，但按 #5 §15.4 定性命中兜底即缺陷，故 #2 仍是 HIGH 而非可豁免项）。
- **降级路径**：N/A——无外部依赖可降级；设计亦未发明任何降级路径。
- **虚假降级识别**：✅ 未发现。设计把「doc 记账不平衡」「generic-diag 到达 IR」两类应永不发生的条件全部 loud assert（§4.5 throw / `semantic.ts:178` 现状 throw），未把任何正常路径的前提缺失伪装成降级。§4.2「peek 抛错路径无需专门处置」不是降级——是相位规则下 E305 无从浮出的正确归宿（有错误在报，非静默）。

## 红线测试思路

（全部经公共入口 `parseVfsl` 断言；`[SA6 owned]`；锚点除注明外已经本评审 node 脚本按码点口径复算）
