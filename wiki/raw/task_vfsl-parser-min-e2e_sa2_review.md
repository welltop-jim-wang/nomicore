## 攻击点清单

| 1 | **HIGH** | 极端输入健壮性 / §14 契约 | **深嵌套输入以 RangeError 击穿「不抛错」契约**。设计的解析主循环是 4 函数互递归（parseUnionType→parsePostfixType→parsePrimaryType→parseObjectType），语义相位 DFS 亦递归。实测（node，同构互递归模拟）：**3129 层嵌套即 `RangeError: Maximum call stack size exceeded`**——约 6KB 对抗性输入（`{a:`×3129 + `string` + `}`×3129）即可让 `parseVfsl` 抛异常。设计 §14 明文承诺「同步、纯函数、**不抛错**（错误仅经返回值传递）」并称该承诺是后续消费方的「集成安全边界」；PRD story 10 把 parser 置于 namespace 创建防线（Phase 2 网络面），ADR-0001 明言「引擎必须在运行时解析**任意**合法方言文本」。此外即便 parser 迭代化，`JSON.stringify` 对深嵌套 IR 同样递归爆栈——SA6 的往返断言本身会抛 | 设计必须显式定义病态深度的行为，三选一并写明理由：(a) 显式深度预算 + 定义好的失败路径（注意 E100 冻结条件是「不可从 §2 文法推导」，深嵌套文本**可推导**——用 E100 拒绝需给出不构成「发明规格外错误」的论证，或在消息中如实说明是实现上限）；(b) parser 与 DFS 全迭代化 + 文档化序列化侧深度限制（此时须收敛 §14 的绝对措辞）；(c) 保持递归但把 §14 承诺改为「对常规输入不抛错」并文档化限制。静默 RangeError 不可接受 |

## 红线测试思路

对每个漏洞的红灯 IT 编写方向（经 `parseVfsl` 公共入口断言，符合 PRD Testing Decisions）：

1. **深嵌套不抛异常**（#1）：`'type A = ' + '{a:'.repeat(N) + 'string' + '}'.repeat(N) + ';'`，N 取 1000 / 5000 / 20000 三档。断言 `expect(() => parseVfsl(text)).not.toThrow()`，且返回值要么 `ok:false` 且 issues 形状合规（若设计定深度预算），要么 `ok:true`（若迭代化）；**禁止**抛 RangeError。别名链版：`type A0 = string; type A1 = A0; … type An = An-1;`（n=20000，DFS 深度）同样断言不抛。若设计允许 ok:true 的深 IR，往返断言须自带 try 或改用浅层对照（测试基础设施考虑）。
2. **超长数字字面量的序列化完整性**（#2）：`'type T = 1' + '0'.repeat(400) + ';'` → 断言结果（按修订立场）为定义好的错误或 ok:true；若 ok:true，断言 `JSON.parse(JSON.stringify(module))` 与 module 深等（当前会失败：Infinity→null），并断言 IR 中该字面量值的口径符合修订后的 §7.3。
3. **字段名位保留名**（#3）：`type T = { type: string };`、`type T = { any: number };` → 按修订立场断言（E100 前缀 + 锚该保留名记号，或 ok:true + IR 含该字段）。
4. **E106 多环取文本最前**（#5）：`'type A = { r: C };\ntype B = { b: B };\ntype C = { c: C };'` → 断言 E106 且锚 line 2 的再入 `B`（非 line 3）。
5. **平衡扫描中的词法错误不被吞**（#7）：`type A = Foo<$>;` → 断言 E100 前缀、line 1、column 13（`$`），而非 column 10（`<`）。
6. **`&` 族锚点**（#6）：`type T = string & Pattern;` → 按修订立场断言锚点（`&` col 11 或 `Pattern` col 13），用例锁修订后的选择。
7. **§2 判读（非代码）**（#4）：SA7 动态验证门槛建议直接写入验收判读：SA3 修绿后 `pnpm test` 必须 **30/30 全绿**；E302/E106 任一失败按实现缺陷打回，不得引用设计 §2 豁免。附议设计 §9 的建议：SA6 补 E308 用例（`type T = { a: string; a: number };` → E308 锚第二个 `a`；正例 `{ a: string; b: number }` ok）。
