# @nomicore/vfsl-protocol

Path-access protocol types consumed by projections generated by `@nomicore/vfsl-codegen`. Install it as a dev dependency alongside the generator and import the generated `PathAt`/`PathValue`/`PathPatchValue` types; see the [repository README](https://github.com/welltop-jim-wang/nomicore#readme) for the full integration guide.
